# Структура CSS в проекте DutyFlow

## Общая структура
css/
├── base/ # Базовые стили
├── components/ # Переиспользуемые компоненты
├── layouts/ # Стили для конкретных страниц
├── themes/ # Темы оформления
└── main.css # Главный файл (импортирует все)



## 1. Папка `base/` - Базовые стили

Содержит фундаментальные стили, которые используются во всем проекте.

| Файл | Назначение |
|------|------------|
| `reset.css` | Сброс стандартных стилей браузера (margin, padding, box-sizing) |
| `variables.css` | CSS-переменные для цветов, теней, анимаций |
| `global.css` | Глобальные стили для body, container, утилиты |

**Правила:**
- Не добавлять сюда стили конкретных компонентов
- Только то, что влияет на весь сайт целиком

## 2. Папка `components/` - Компоненты

Стили для переиспользуемых UI-компонентов.

| Файл | Назначение |
|------|------------|
| `buttons.css` | Все кнопки (btn, btn-primary, btn-secondary, btn-danger) |
| `cards.css` | Карточки (card, card-header, card-body) |
| `forms.css` | Формы (form-group, form-input, form-select) |
| `tables.css` | Таблицы (table, table-container) |
| `badges.css` | Бейджи и статусы (badge, badge-success) |
| `navigation.css` | Навигация (nav, menu, breadcrumbs) |
| `theme-toggle.css` | Кнопка переключения темы |

**Правила:**
- Один файл = один компонент
- Стили не должны зависеть от контекста страницы
- Максимальная переиспользуемость

## 3. Папка `layouts/` - Макеты страниц

Стили для конкретных страниц или типов страниц.

| Файл | Назначение |
|------|------------|
| `auth.css` | Страница входа |
| `cabinet.css` | Личный кабинет (шапка, структура) |
| `dashboard.css` | Дашборд (статистика, карточки) |
| `landing.css` | Главная страница |

**Правила:**
- Стили специфичны для конкретной страницы
- Могут использовать компоненты из `components/`

## 4. Папка `themes/` - Темы оформления

| Файл | Назначение |
|------|------------|
| `light.css` | Светлая тема (переопределяет переменные) |
| `dark.css` | Темная тема (переопределяет переменные) |

**Как работают темы:**
1. В `variables.css` определены базовые переменные
2. Темы переопределяют эти переменные
3. Переключение тем через JavaScript

## 5. `main.css` - Главный файл

Импортирует все CSS-файлы в правильном порядке:

```css
/* Сначала базовые */
@import 'base/reset.css';
@import 'base/variables.css';
@import 'base/global.css';

/* Потом компоненты */
@import 'components/buttons.css';
@import 'components/cards.css';
/* ... */

/* Потом макеты */
@import 'layouts/auth.css';
/* ... */

Правила именования классов
Используем BEM-подобную нотацию:

Блок: .card, .btn, .form

Элемент: .card__header, .btn__icon

Модификатор: .btn--primary, .card--compact

<div class="card card--compact">
  <div class="card__header">
    <h2 class="card__title">Заголовок</h2>
  </div>
  <div class="card__body">
    <button class="btn btn--primary">Кнопка</button>
  </div>
</div>


Добавление новых стилей
Определите, что вы создаете:

Новый компонент → файл в components/

Новая страница → файл в layouts/

Новая тема → файл в themes/

Импортируйте новый файл в main.css

Используйте существующие переменные из variables.css


Переменные цветов
Основные переменные в variables.css:


:root {
  --primary: #2563eb;        /* Основной цвет */
  --success: #22c55e;        /* Успех */
  --warning: #eab308;        /* Предупреждение */
  --danger: #ef4444;         /* Опасность */
  
  --text: #0f172a;           /* Основной текст */
  --text-muted: #64748b;     /* Второстепенный текст */
  
  --bg-body: #f8fafc;        /* Фон страницы */
  --bg-card: #ffffff;        /* Фон карточек */
  --border: #e2e8f0;         /* Границы */
}


Советы по поддержке
Не дублируйте код - если стиль используется в двух местах, вынесите в компонент

Следите за специфичностью - избегайте вложенности глубже 3 уровней

Комментируйте сложные моменты

Тестируйте в обеих темах (светлой и темной)
