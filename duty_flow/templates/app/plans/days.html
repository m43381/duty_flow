Автоматизация распределения

Режимы автораспределения:
Равномерно по структуре — распределяет по подразделениям и нагрузке без проверки сотрудников.
Равномерно с учётом людей — учитывает допуски, освобождения, занятость и требуемое количество людей.
Только дочерние по структуре — исключает базовое подразделение и распределяет только вниз.
Только дочерние с учётом людей — делегирует только вниз и проверяет кадровую выполнимость.
Приоритет своим — старается оставлять наряды в базовом подразделении.
Приоритет дочерним — старается отдавать наряды вниз по структуре.
Нормализовать по размеру подразделения — крупные подразделения получают чуть больше нагрузки.
